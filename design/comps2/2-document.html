Configuration over a queue

At EY I work on the POS and menu configuration platform for a national quick-service restaurant chain. Chain-wide configuration operations ran over synchronous HTTP and timed out.

I re-architected them as SQS batch processing. The worker applies each message idempotently, so a retry is safe; a message that keeps failing lands in a dead-letter queue, which raises an alert. The timeouts across 3,500+ locations stopped.

The same period I cut P95 latency on the customer-facing POS endpoints by 65 percent, with Redis caching and query rewrites; more on that below.
