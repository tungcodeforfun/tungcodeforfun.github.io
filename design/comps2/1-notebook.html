Chain-wide configuration, moved onto a queue

At EY I work on the POS and menu configuration platform for a national quick-service restaurant chain. Chain-wide configuration operations ran over synchronous HTTP and timed out.

I re-architected them as SQS batch processing. The worker applies each message idempotently, so retrying is safe, and a message that keeps failing goes to a dead-letter queue that raises an alert. The timeouts across 3,500+ locations stopped.
