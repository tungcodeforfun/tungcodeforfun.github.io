Chain-wide configuration, moved onto a queue

Chain-wide configuration operations ran over synchronous HTTP and timed out.

I re-architected them as SQS batch processing. The worker applies each message idempotently, so retrying is safe, and a message that keeps failing lands in a dead-letter queue that raises an alert. The timeouts across 3,500+ locations stopped.

Narrowing venue menus

Venue menus listed 1,300+ items. I led the event-driven integration with an upstream menu-eligibility platform: its data comes in over SNS and SQS, and venue-aware APIs serve the result. A cross-account backfill of 1,000+ locations ran idempotently, behind per-store flags. Venue menus went from 1,300+ items to about 130.The backfill sat behind per-store flags, so each location could be switched on separately.

Caching the POS hot path
